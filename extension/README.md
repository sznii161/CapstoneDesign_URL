# 피싱 URL 검사 확장 프로그램: 교수 면담 시연용

이 폴더는 Chrome에 바로 설치할 수 있는 Manifest V3 확장 프로그램입니다. 인터넷 연결이나 서버 없이 팝업과 상세 패널을 보여줄 수 있습니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드**를 누르고 이 폴더(`phishing_extension_demo`)를 선택합니다.
4. Chrome 오른쪽 위 퍼즐 모양 아이콘에서 **피싱 URL 검사 - 시연용**을 고정합니다.
5. 일반 웹사이트 탭을 연 뒤 확장 아이콘을 누릅니다. `chrome://extensions` 같은 Chrome 내부 페이지에서는 현재 URL 검사가 제한됩니다.

이미 확장을 로드한 뒤 파일을 수정했다면 `chrome://extensions`에서 이 확장의 **새로고침** 버튼을 누르고 팝업을 다시 여세요.

상단의 SCH 로고와 확장 아이콘은 [순천향대학교 공식 UI 다운로드](https://home.sch.ac.kr/sch/01/020310.jsp)의 PNG 원본을 사용합니다. 검사 결과 캐릭터는 기존 그림을 유지합니다. 학교의 [UI 사용 안내](https://home.sch.ac.kr/sch/01/020308.jsp)를 확인한 뒤 학교 밖 공개·배포 여부를 결정하세요.

## 교수님께 보여줄 순서

1. 팝업의 **현재 페이지**에 URL이 자동으로 나타나는 것을 보여줍니다.
2. **시연용 의심 주소 넣기**를 눌러 URL 구조 주의 신호가 표시되는 것을 보여줍니다. 이 주소는 `.example` 형식의 가상 주소입니다.
3. **상세 보기**를 눌러 브라우저 오른쪽에 상세 패널이 열리는 것을 보여줍니다.
4. 팝업의 **이메일 검사** 탭에서 **시연용 이메일 넣기**를 눌러 제목·본문 입력과 규칙 검사 결과를 보여줍니다.

## 지금 동작하는 것과 다음 단계

| 지금 동작하는 것 | 다음 단계 |
| --- | --- |
| 확장 팝업과 오른쪽 상세 패널 | AI 모델/API 연동 |
| 현재 탭 URL 자동 읽기와 직접 입력 | RDAP/WHOIS 등록정보 조회 |
| URL 구조의 기본 규칙 검사 | 위험 페이지 경고 배너 |
| 이메일 제목·본문의 문구/링크 규칙 검사 | 동의 후 화면 비교, 신고 서버 |

지금 결과는 **규칙에 해당하는 신호를 보여주는 프로토타입**입니다. 피싱 여부나 모델 정확도를 주장하지 않습니다. 이메일 본문은 전송하거나 저장하지 않습니다. 마지막 URL 검사 결과만 확장 세션 저장소에 임시로 보관해 상세 패널에 전달합니다.

교수님께는 이렇게 설명하면 됩니다: “현재 크롬 확장 프로그램의 화면 흐름과 현재 페이지 URL 읽기, URL·이메일 입력, 1차 규칙 검사를 구현했습니다. AI 모델과 API, 등록정보 조회, 신고 기능은 다음 단계로 연결할 예정입니다.”
