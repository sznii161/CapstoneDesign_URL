# URL 탐지 모델 v1

원본 URL 문자열을 문자 TF-IDF + 로지스틱 회귀 Pipeline으로 분류한다. 이 폴더만 복사하면 기존 프로젝트 경로 없이 실행할 수 있다. 모델·어휘·IDF와 임계값 0.5는 고정되어 있다. URL에 접속하지 않는다.

## 설치와 실행: Windows PowerShell

검증 환경은 Windows x64, Python 3.14.6이다. 고정 NumPy·SciPy의 요구 조건 때문에 Python 3.12 이상이 필요하며 같은 Python 버전을 권장한다. 새 환경에서의 패키지 다운로드·설치는 이번 검증에 포함하지 않았다.

이 폴더 전체를 복사하고 해당 폴더에서 실행한다.

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
.\.venv\Scripts\python.exe .\example.py "https://example.org/"
```

다른 작업 폴더에서도 `example.py`의 전체 경로로 실행할 수 있다. 모델 경로는 현재 작업 폴더가 아니라 `inference.py`의 위치를 기준으로 해석한다.

## 함수 호출

```python
from inference import load_detector, predict_url

load_detector()  # 프로그램 시작 시 한 번 로딩
result = predict_url("https://example.org/")  # 같은 객체 재사용
print(result)
```

실제 전달 검증에서 얻은 반환 예시:

```json
{
  "phishing_score": 0.39873528913396306,
  "predicted_label": 1,
  "model_version": "url_detector_v1"
}
```

`classes_`에서 피싱(0)의 확률 열을 확인한다. `phishing_score >= 0.5`이면 `predicted_label=0`(피싱), 그 외는 `1`(정상)이다. `model_version`은 `url_detector_v1`이다. 점수는 보정된 실제 위험 확률로 검증된 값이 아닌 모델 출력이다. 정상 판정도 안전을 보장하지 않는다.

잘못된 타입·빈 문자열·해석할 수 없는 호스트나 포트 등은 `ValueError`로 거부하며 정상으로 자동 처리하지 않는다. 함수 호출자는 `try/except`로 오류를 처리한다. CLI는 오류 JSON과 종료 코드 2를 반환한다.

기존 통합 예제의 입력 정책을 그대로 유지한다. 스킴 없는 주소는 호스트 확인용 임시 파싱만 하고 원문을 모델에 전달한다. HTTPS 추가·디코딩·문자열 자르기·접속은 하지 않는다. sklearn 문자 분석기 자체의 연속 공백 정규화는 그대로다.

## 고정 공식 test 평가

| 지표 | 공식 test 전체 | URL·도메인 미겹침 보조 집합 |
|---|---:|---:|
| 표본 수 | 168,060 | 71,802 |
| Accuracy | 93.68% | 88.04% |
| Balanced Accuracy | 93.32% | 89.19% |
| 피싱 Precision | 96.80% | 96.21% |
| 피싱 Recall | 89.13% | 83.26% |
| 피싱 F1 | 92.80% | 89.27% |
| 정상 오탐률 | 2.48% | 4.88% |
| 피싱 미탐률 | 10.88% | 16.74% |

미겹침 보조 집합은 train·validation 어느 쪽과도 원문 URL 및 등록 도메인이 겹치지 않고 도메인을 판단할 수 있는 행이다. 전체 평가 커버리지는 100%이며 중복·정답 충돌·입력 거부·예측 실패는 없었다. 도메인 판단 실패 1행은 전체 평가에 포함하고 보조 집합에서는 제외했다. 제공 날짜는 2025-09-08~2025-12-16이며 미래 시점 평가라고 부르지 않는다.

정상 루트 8,083행 중 오탐 1,078건(13.34%), 피싱 상세 28,915행 중 미탐 5,474건(18.93%)이 남았다. 한국어는 총 174행이며 정상 9행·피싱 165행이다. 정상 오탐 0건, 피싱 미탐 14건이지만 표본이 적어 한국어 일반 성능을 보장하지 않는다. 쿼리는 경로 구분과 겹친다. 지표·혼동행렬·구성별 결과는 `evaluation_summary.json`에 있다.

이 결과는 고정 모델의 공식 test 평가이며 실제 서비스 성능을 보장하지 않는다. test에 따른 재학습·모델 선택·임계값 변경은 하지 않았다. 개발용 정상 probe 52개에서는 오탐 5건(9.62%), 추가 validation 정상 40개에서는 0건이었다. 이 두 자료는 이미 개발에 참고해 독립적인 최종 평가가 아니다.

## 로컬 추론 시간

파일 약 2.01MiB, 1회 로딩 738.67ms. validation에서 random_state=42로 선택한 1,000개 URL을 20회 워밍업 후 하나씩 처리했을 때 중앙값 2.25ms, 평균 2.41ms, 95백분위 3.50ms였다. 입력 검증·TF-IDF·predict_proba·점수와 라벨 반환 범위다. Python·라이브러리 import는 로딩 시간에 포함하지 않았고 OS 파일 캐시가 영향을 줄 수 있다. API·네트워크·브라우저 확장을 포함한 전체 응답시간이 아니다.

## 파일·출처·GitHub 공유

모델 해시·버전·라벨·설정·필수 패키지는 `metadata.json`, 출처·이용 조건은 `DATA_SOURCE.md` 및 `DATASET_CARD.md`, 전달 검증은 `verification.json`, 파일 해시는 `SHA256SUMS.json`에 있다.

데이터·모델·코드의 라이선스는 구분한다. 데이터 라이선스가 모델·코드에 자동 적용된다고 단정하지 않았고 코드·모델 라이선스를 임의로 지정하지 않았다. 배포 라이선스 결정은 소유자의 별도 검토 사항이다.

GitHub에는 이 폴더의 파일 전체만 올린다(약 2MiB 모델 포함). `.gitignore`도 함께 커밋한다. 원본 데이터, 행별 예측 파일, 상위 프로젝트, `.venv`, 캐시, 인증정보는 포함하지 않는다. 이 작업에서는 원격 저장소 생성·커밋·push를 하지 않았다.
