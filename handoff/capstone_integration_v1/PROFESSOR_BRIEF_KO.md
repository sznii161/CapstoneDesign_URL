| 영역 | 구현 완료 | 평가 완료 | 미검증·추후 과제 |

| URL | URL 문자열을 고정 모델로 분류 | PhreshPhish 공식 test, 비겹침 보조 집합 | 실제 서비스의 URL 분포와 운영 오경고 |
| 이메일 | 제목·본문 판정, 원문 링크의 별도 분석, 오류 상태 반환 | 개발용 검증 576건, 기존·새 외부 개발 점검 | 독립 최종 시험 0건. 한국어 원본 대조군 필요 |

> 발표 메모. 구현 범위는 Python 추론 함수까지다. URL·메일·화면은 서로 다른 평가 단위다.

### 2. URL 공식 시험

| PhreshPhish 고정 공식 시험 | 표본 | 정확도 | 피싱 Recall | 정상 오탐률 |
|---|---:|---:|---:|---:|
| 전체 | 168,060 | 93.68% | 89.13% | 2.48% |
| URL·등록 도메인 비겹침 보조 | 71,802 | 88.04% | 83.26% | 4.88% |

전체에서 피싱 76,800건 중 **68,448건 탐지·8,352건 미탐**, 정상 91,260건 중 **2,266건 오탐**이다. 모델은 URL 문자열을 점수화한다. 보조 집합의 기준과 표본이 별도이므로 각 수치를 표시한다. 이 공식 데이터셋 시험 수치는 실제 서비스 성능을 보장하지 않는다.

> 출처. `handoff/url_detector_v1/evaluation_summary.json`, `reports/phreshphish_char_tfidf_final_test_v1/report_ko.md`.

### 3. 이메일 내부 검증과 기본 판정

| 내부 개발 검증 576건 | 피싱 탐지 / 미탐 | 정상 오탐 |
|---|---:|---:|
| 현재 단어 모델 | 15 / 1 | 0 |
| 기존 본문 또는 URL 경고 | 15 / 1 | 363 |
| 추출 수정 후 본문 또는 URL 경고 | 15 / 1 | 354 |

수정 후 OR도 **추가 탐지 0건, 추가 오탐 354건**이다. 반복된 정상 메일링리스트·약관 링크가 URL 경고를 만들었다. 기본 이메일 경고는 본문 모델의 `final_warning`을 사용하고 링크는 별도 표시한다.

> 출처. `reports/capstone_email_audit_v2/results.json`.

### 4. 문자 모델을 서비스에 연결하지 않은 근거

내부 개발 비교에서 문자 모델은 피싱 **16/16**, 단어 모델은 **15/16**, 정상 오탐은 각각 **0/560**이었다.

외부 개발 비교에서 기존 LMU 피싱 1건과 Michigan 계정 사칭 4건은 **두 모델 모두 탐지**했다. 추가 정상 1,265건은 단어 오탐 **0**, 문자 오탐 **1**이었다. 정상은 학습과 동일 배포처의 추가 코퍼스다. 별도 캠페인의 영어 정상·피싱 대조와 한국어 독립 시험이 필요하다. 이메일 독립 최종 평가 수는 **0건**이다.

> 발표 메모. 내부에서 1건 더 맞힌 결과만으로 서비스 교체를 결정하지 않았다. 실제 외부 정합성이 확인될 때까지 현 단어 가중치를 고정한다.
>
> 출처. `reports/capstone_development_v3/email_comparison.json`, `reports/capstone_external_v4/comparison.json`, `campus_account_results.json`.

### 5. 화면 분석의 현재 수준

| 점검 | 표본 | 관찰한 결과 |
|---|---:|---|
| 공식 로그인 | 5 | 해당 브랜드 1위 5건, 허용 호스트 일치 5건 |
| 무관한 화면 | 3 | 모든 화면에 1위 후보 발생. PyPI 로그인은 네이버 0.8673 |
| 공식 이미지와 주소 변경 모의 | 3 | 1위 브랜드 일치 3건, 허용 호스트 일치 0건 |
| 실제 사칭 캡처 | 2장 확보, 평가 0장 | 네이버·카카오 같은 캠페인, 우리은행 확보 0장 |

비교 화면별 CPU 중앙값은 약 **27–60 ms**였다. 화면 분석은 `similarity_only`이며 임계값은 비어 있다. 화면 유사도·1위 브랜드·호스트 불일치는 사칭 확정으로 표시하지 않는다.

> 출처. `reports/capstone_development_v3/login_evaluation.json`, `reports/capstone_external_v4/public_screen_inventory.json`.

### 6. 교수님 앞 시연 순서

1. 통합 ZIP을 푼 폴더에서 `python -m capstone_models.example`을 실행한다.
2. 이메일 결과의 본문 점수 **0.1893**, 링크 점수 **0.6763**과 `final_warning=false`를 함께 보여준다. 링크 경고가 독립적으로 표시되는 것을 확인한다.
3. `python verify_package.py`에서 URL 검사 실패와 링크 없음의 다른 상태, 본문 또는 화면 가중치가 없을 때의 처리를 확인한다.
4. 네이버 기준 이미지 호출에서 `similarity_only`와 허용 호스트 일치를 보여준다. 무관한 화면에 1위가 생기는 실측은 앞 표로 설명한다.

시연 확인 범위는 함수 로딩과 결과 계약이다. 공식 시험 결과와 시연을 구분한다. 시연으로 한국어 이메일 재현율, 실제 사칭 탐지율, 첨부 공격 탐지, 브라우저·API 운영 성능을 측정할 수 없다.
